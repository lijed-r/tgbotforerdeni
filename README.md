# Telegram Userbot (Telethon)

Telegram userbot для автоматической пересылки постов между каналами.

## 🚀 Возможности

- Пересылка новых сообщений, в том числе если пересылка запрещена
- Поддержка текста, фото, видео, документов
- Обработка альбомов
- Отслеживание редактирования постов
- Анти-спам защита (rate limit + задержки)
- Автоматическая обработка FloodWait
- Логирование

---

## ⚙️ Технологии

- Python 3.10+
- Telethon
- Asyncio
- Deque (скользящее окно)
