### 2. [telegram_userbot.py](file:///c:/Users/Kirill/Desktop/курсач/telegram_userbot.py)

Полностью рабочий Python-скрипт со следующими возможностями:

#### ✅ Реализованные функции

**Основной функционал**:
- ✅ Авторизация через `api_id` и `api_hash`
- ✅ Прослушивание новых сообщений из списка каналов
- ✅ Пересылка в целевой канал
- ✅ Обработка всех типов медиа (текст, фото, видео, документы)

**Анти-спам механизмы**:
- ✅ Случайная задержка 5-20 секунд перед каждой пересылкой
- ✅ Ограничение до 30 пересылок в час
- ✅ Скользящее окно учета (rolling window) для точного подсчета
- ✅ Автоматическое ожидание при превышении лимита

**Обработка ошибок**:
- ✅ `FloodWaitError` — автоматическое ожидание и продолжение работы
- ✅ `RPCError` — логирование и продолжение работы
- ✅ Общие исключения — graceful degradation

**Логирование**:
- ✅ Временные метки для каждого события
- ✅ Информация об источнике поста
- ✅ Статус пересылки
- ✅ Счетчик пересылок в реальном времени
- ✅ Emoji-индикаторы для удобства чтения

#### 🎯 Ключевые особенности реализации

**Умный rate limiting**:
```python
forwards_history = deque()  # Очередь с историей пересылок
```
Используется `deque` для эффективного хранения временных меток пересылок и реализации скользящего окна в 1 час.

**Асинхронная обработка**:
Все операции выполняются асинхронно через `async/await`, что обеспечивает неблокирующую работу при ожидании задержек.

**Гибкая конфигурация**:
Все настройки вынесены в начало файла как переменные — легко изменить без редактирования кода.

## 🚀 Быстрый старт

### Шаг 1: Установка зависимостей

```bash
pip install telethon
```

### Шаг 2: Получение API credentials

1. Перейдите на https://my.telegram.org
2. Войдите с вашим номером телефона
3. Перейдите в "API development tools"
4. Создайте приложение и скопируйте `api_id` и `api_hash`

### Шаг 3: Настройка скрипта

Откройте [telegram_userbot.py](file:///c:/Users/Kirill/Desktop/%D0%BA%D1%83%D1%80%D1%81%D0%B0%D1%87/telegram_userbot.py) и укажите:

```python
api_id = 12345678  # Ваш api_id
api_hash = 'your_api_hash_here'  # Ваш api_hash
source_channels = ['channel1', 'channel2']  # Каналы-источники
target_channel = 'my_target_channel'  # Целевой канал
```

### Шаг 4: Запуск

```bash
python telegram_userbot.py
```

При первом запуске введите:
- Номер телефона (формат: +79001234567)
- Код подтверждения из Telegram
- Пароль (если включена 2FA)

### Шаг 5: Проверка

После запуска вы увидите:
```
[2026-02-09 21:57:11] 🔐 Вход выполнен как: Your Name (@username)
[2026-02-09 21:57:11] 🤖 Userbot запущен и слушает каналы...
[2026-02-09 21:57:11] 📋 Отслеживаемые каналы: ['channel1', 'channel2']
[2026-02-09 21:57:11] 🎯 Целевой канал: my_target_channel
```

Скрипт теперь работает и будет автоматически пересылать новые посты!
